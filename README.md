Цветная консольная версия классической «Змейки». Игра использует PDCurses
для позиционирования курсора, обработки стрелок и цветного вывода в терминале.

## Правила

Управляйте змейкой, собирайте яблоки `@` и увеличивайте длину хвоста. Игра
заканчивается при столкновении с рамкой или собственным телом.

Обозначения:

- `$` — голова змейки;
- `#` — хвост;
- `@` — яблоко;
- `*` — граница поля.

## Управление

- **стрелки** — изменить направление;
- **Q** — выйти;
- после поражения **N** — начать заново;
- после поражения **Q** — завершить игру.

Разворот сразу в противоположную сторону блокируется, чтобы змейка не
столкнулась с собой за один кадр.

## Технические детали

- координаты головы и хвоста хранятся в `vector2di`;
- хвост представлен `std::vector` координат;
- яблоки появляются в случайных свободных клетках;
- `timeout()` задаёт частоту обновления;
- вертикальное и горизонтальное движение имеют отдельные задержки кадра;
- интерфейс использует пять цветовых пар PDCurses.

## Сборка

В репозитории уже находятся заголовки `curses.h`, `panel.h` и библиотека
`pdcurses.lib`.

1. Откройте `MyNcurses.sln` в Visual Studio 2022.
2. Выберите нужную платформу проекта.
3. В свойствах C/C++ добавьте `$(ProjectDir)` в каталоги заголовков.
4. В свойствах компоновщика добавьте `$(ProjectDir)` в каталоги библиотек.
5. Убедитесь, что в зависимостях указан `pdcurses.lib`.
6. Соберите и запустите консольное приложение.

> В текущем `.vcxproj` сохранён абсолютный путь с другого компьютера. Его
> необходимо заменить на `$(ProjectDir)` по инструкции выше.
